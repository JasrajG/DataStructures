- It is not recommended for your leanring by only looking at the solution. It only internalizes as part of your skills if you are able to reproduce the solution on your own.

- The solution project also contains extra JUnits tests.

0. To run all tests, right-click on AllTests.java and run it as a JUnit test.
1. You may start by using these tests to evaluate your submitted solution.
2. Then use the debugger to find where the errors are, if any, and fix them accordingly.
3. Then look at the reference solution.
4. Finally, practice by re-solving the problems, from scratch, with the goal to pass all tests.
